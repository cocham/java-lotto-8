## [로또]

## 1\. 기능 구현 목록

### 1.1. 로또 구입 및 발행

* **구입 금액 입력:** `구입금액을 입력해 주세요.` 출력 후 입력 받음.
    * 로또는 **1,000원** 단위로 발행 횟수 결정.
* **로또 번호 생성:** **1**부터 **45** 사이의 숫자 중 **중복 없는 6개**를 무작위로 생성.

### 1.2. 구매 내역 출력

* **구매 내역 출력:** 발행한 로또 수량과 각 로또 번호 출력.
    * 로또 번호는 항상 **오름차순**으로 정렬.
* **출력 양식:**
  ```
  {수량}개를 구매했습니다.
  [8, 21, 23, 41, 42, 43] 
  [3, 5, 11, 16, 32, 38] 
  ... (나머지 로또)
  ```

### 1.3. 당첨 정보 입력

* **당첨 번호 입력:** `당첨 번호를 입력해 주세요.` 출력 후 입력 받음.
    * 쉼표(`,`)를 기준으로 분리하며, 숫자 앞뒤 공백 제거.
* **보너스 번호 입력:** `보너스 번호를 입력해 주세요.` 출력 후 입력 받음.

### 1.4. 결과 계산 및 출력

* **로또 추첨 (당첨 기준):** 당첨 번호와 발행 번호를 비교하여 등수 결정.
    * 1등: 6개 일치 (**2,000,000,000원**)
    * 2등: 5개 일치 + 보너스 번호 일치 (**30,000,000원**)
    * 3등: 5개 일치 (**1,500,000원**)
    * 4등: 4개 일치 (**50,000원**)
    * 5등: 3개 일치 (**5,000원**)
* **당첨 통계 출력:** 당첨 기준별 수량과 상금 출력.
    * **출력 양식:**
  <!-- end list -->
  ```
  당첨 통계
  ---
  3개 일치 (5,000원) - {개수}개
  4개 일치 (50,000원) - {개수}개
  5개 일치 (1,500,000원) - {개수}개
  5개 일치, 보너스 볼 일치 (30,000,000원) - {개수}개
  6개 일치 (2,000,000,000원) - {개수}개
  ```
* **수익률 출력:** 총 수익률을 계산하여 출력.
    * **소수점 둘째 자리에서 반올림**
    * **출력 양식:** `총 수익률은 {수익률}%입니다.` (예: `총 수익률은 62.5%입니다.`)

## 2\. 예외 처리 및 재입력 정책

모든 예외 상황 발생 시 \*\*`"[ERROR]"`\*\*로 시작하는 메시지를 출력하고, 해당 입력을 **다시 받음.**

### 2.1. 입력 공통 예외 (모든 입력에 적용)

| 예외 상황 | 발생 클래스 |
| :--- | :--- |
| 입력 값이 \*\*`NULL`\*\*이거나 빈 값일 경우 | `NullInputException` |
| 입력 값이 **정수**로 변환될 수 없을 경우 | `InvalidNumberException` |

### 2.2. 구입 금액 관련 예외

| 예외 상황 | 범위/규칙 | 발생 클래스 |
| :--- | :--- | :--- |
| **금액 범위** | **1,000원 미만** 또는 **100,000원 초과** 시 | `OutOfRangeMoneyException` |
| **금액 단위** | **1,000원의 배수**가 아닐 시 | `InvalidLottoMoneyException` |

### 2.3. 로또 번호 관련 예외

| 예외 상황 | 대상 | 발생 클래스 |
| :--- | :--- | :--- |
| **개수 불일치** | 당첨 번호가 **6개**가 아닐 시 | `InvalidLottoSizeException` |
| **숫자 범위** | 번호가 **1 이상 45 이하**가 아닐 시 | `InvalidLottoNumberException` |
| **중복 번호** | 당첨 번호 내, 또는 당첨 번호와 보너스 번호 간 **중복** 시 | `NumberDuplicateException` |

## 3\. 주요 클래스 및 역할 요약

| 분류 | 클래스 이름 | 주요 역할 |
| :--- | :--- | :--- |
| **Controller** | **`LottoController`** | **애플리케이션 흐름 제어 및 조율.** <br> 전체 게임 프로세스 관리 및 **예외 발생 시 재입력** 로직(`retryOnException`) 구현. |
| **Service** | **`LottoService`** | **도메인 로직 조정자.** <br> 로또 구매(`LottoGenerator` 사용) 및 당첨 결과(`LottoResult`, `Yield` 사용) 계산 총괄. |
| **Configuration** | **`AppConfig`** | **의존성 주입(DI) 컨테이너.** <br> `Service`, `Generator`, `View` 등 주요 객체 인스턴스를 생성하고 관리. |
| **View** | **`InputView`** | 사용자 **입력 처리.** <br> 메시지 출력, 콘솔 입력 읽기 및 **`NULL`/빈 문자열 검사** 수행. |
| | **`OutputView`** | **결과 출력 담당.** <br> 구매 내역, 당첨 통계, 에러 메시지 등을 사용자에게 출력. |
| **Domain** | **`Money`** | **구입 금액** 모델. 유효성 검사 및 **로또 구입 가능 개수** 계산. |
| | **`Lotto`** | **로또 한 장 (6개 번호) 모델.** 번호 유효성 검사 및 불변성 보장. |
| | **`Lottos`** | **구매한 로또 묶음** 컬렉션 관리. 출력용 정렬된 번호 리스트 제공. |
| | **`WinningLotto`** | **당첨 번호 모델.** 구매 로또와 비교하여 `LottoRank` 결정. |
| | **`LottoBonusNumber`** | **보너스 번호 모델.** 생성 시 유효성 검사 (범위, 당첨 번호 중복). |
| | **`LottoRank`** | **로또 등수(순위) 및 상금** 정의 Enum. 일치 정보에 따라 등수를 결정. |
| | **`LottoResult`** | **전체 로또의 당첨 통계** 계산. 순위별 횟수 및 **총 상금** 계산. |
| | **`Yield`** | **수익률** 계산. **소수점 둘째 자리 반올림** 로직 포함. |
| **Utility** | **`LottoGenerator`** | `Money`를 기반으로 `Lotto`를 생성하고 `Lottos` 묶음으로 반환. <br> `NumberGenerator`에 번호 생성 위임. |
| | **`RandomNumberGenerator`** | **`NumberGenerator`** 구현체. **1\~45** 범위에서 **6개** 숫자를 무작위 생성. |
| | **`NumberGenerator`** | 로또 번호 생성 전략을 정의하는 **인터페이스**. |
| | **`InputParser`** | **입력 문자열 파싱** 유틸리티. 쉼표 분리, `String`을 `Integer`로 변환 시 `NumberFormatException` 처리. |
| | **`LottoValidation`** | **정적 유틸리티** 클래스. 로또 번호의 크기, 범위, 중복 등 핵심 유효성 검사 로직 모음. |
